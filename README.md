⚡ VoltRelay_DAH | Data Analytics Project

📌 Project Overview

VoltRelay_DAH is a data analytics project focused on exploring and analyzing electric vehicle (EV) battery-swapping operations.
The project uses station-level and battery-swapping event data to explore operational patterns, station activity, and trends through data analysis.

🎯 Project Objectives

Explore and understand the available datasets.
Perform data cleaning and preprocessing.
Identify missing values, duplicates, and inconsistencies.
Analyze station-level activity and battery-swapping events.
Discover meaningful patterns and operational trends.
Generate actionable insights through exploratory data analysis.
